# Matrix Bot Landing Page Design

## Overview
A Matrix-themed landing page for the "Matrix Bot" business — an AI-powered WhatsApp agent platform. The page features a full-screen Matrix digital rain animation background with a live chat widget where visitors interact with a sales AI agent.

## Visual Design
- Full-screen Matrix rain background using HTML5 Canvas
- Green Katakana + Latin + numbers cascading on pure black
- Bright green (#0F0) character heads with fading trails via transparent black overlay
- Content floats on top with semi-transparent dark panels for readability

## Page Layout (single scroll)

### 1. Hero Section (centered)
- "Matrix Bot" logo in glowing green monospace font with pulsing text-shadow
- Tagline: "AI-Powered WhatsApp Agents for Your Business"
- CTA button: "Talk to our Agent" — opens the chat widget

### 2. Chat Widget (main interaction)
- Panel on right side, styled as Matrix terminal console
- Green-on-black, monospace font
- WhatsApp-style message bubbles in Matrix green tones
- Typing indicator with flickering character animation
- Mock responses: pre-scripted sales conversation about WhatsApp agent capabilities
- Green glow border on input field

### 3. Features Section (below fold)
- 3-4 cards: "24/7 AI Agent", "WhatsApp Integration", "Voice Cloning", "Smart Booking"
- Dark semi-transparent backgrounds with green borders/accents

### 4. Footer
- Minimal: copyright + "Powered by Matrix Bot"

## Tech Stack
- Single `index.html` file — all HTML, CSS, JS inline
- Canvas API for Matrix rain
- Pure CSS animations for glows, pulses, typing
- Zero dependencies

## Chat Widget Mock Behavior
- Pre-scripted sales conversation flow
- Bot responds to any user input with next message in sequence
- 1-2 second simulated typing delay with character flicker
- Messages appear with green glow-in animation
